# Cross-project integrations

Links below are **resolved from the other projects' OpenAPI specs at build time** — if an operation is renamed or removed, the portal build fails instead of shipping a broken link.

| Operation | Why Accounts & Balances uses it |
|---|---|
| <ApiRef project="kyc" op="getParty" /> | Resolve `owner.partyId` to the verified customer. |
| <ApiRef project="payments" op="getPayment" /> | Transactions with `sourceSystem = PAYMENTS` reference a `paymentId`. |
| <ApiRef project="cards" op="listAuthorisations" /> | Holds with `sourceSystem = CARDS` reference an `authorisationId`. |
| <ApiRef project="fx" op="getTrade" /> | Settlements with `sourceSystem = FX` reference a `tradeId`. |
