# Getting started with Payments Hub

1. **Request access** — raise an *API Access* request for scope(s) listed in the [API Reference](/payments/api). Sandbox access is auto-approved.
2. **Get a token** — all Meridian APIs share one OAuth2 client-credentials flow (see [Platform → API Standards](/platform/api-standards#authentication)).
3. **Call the sandbox**:

```bash
TOKEN=$(curl -s -X POST https://auth.meridian.example/oauth2/token \
  -d grant_type=client_credentials -d client_id=$CLIENT_ID -d client_secret=$CLIENT_SECRET | jq -r .access_token)

curl -X POST https://sandbox.api.meridian.example/payments/v2/payments \
  -H "Authorization: Bearer $TOKEN" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "debtorAccount": {"accountId": "acc_9f2c1e7b"},
    "creditor": {"name": "Acme Ltd", "account": {"iban": "DE89370400440532013000"}},
    "amount": {"amount": "1250.00", "currency": "EUR"},
    "rail": "SEPA_CT",
    "fxQuoteId": "fxq_a1b2c3"
  }'
```

4. **Try it in the browser** — every operation page in the API Reference has a *Send API Request* panel pointed at the sandbox.

:::tip Idempotency
Every write requires an `Idempotency-Key` header (shared parameter, see <SchemaRef project="payments" name="Problem" /> for error shape).
:::
