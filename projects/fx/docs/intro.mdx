# FX & Treasury

:::info Project facts
**Domain:** Markets · **Owner:** Treasury Technology · **Status:** Beta · **Version:** v1.2.0-beta
:::

FX & Treasury provides indicative rates, executable quotes and trade booking. **Status: Beta** — breaking changes are possible before 2.0.
